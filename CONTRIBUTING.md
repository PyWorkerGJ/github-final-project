# Contributing to Simple Interest Calculator

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

Thank you for taking the time to help improve this project!

## Code of Conduct

By participating in this project, you agree to follow our [Code of Conduct](CODE_OF_CONDUCT.md).

## Ways to Contribute

- **Report bugs**: open an [issue](https://github.com/PyWorkerGJ/simple-interest-calculator/issues) describing the problem, the steps to reproduce it, and the expected vs. actual result.
- **Fix bugs**: look for open issues and submit a pull request with a fix.
- **Improve documentation**: corrections, clearer explanations and new examples are always appreciated.
- **Suggest enhancements**: open an issue describing the feature and why it would be useful.
- **Share ideas**: start a discussion in an issue; every idea is welcome.

## How to Submit a Pull Request

1. Fork the repository.
2. Create a new branch for your change:

   ```bash
   git checkout -b my-change
   ```

3. Make your changes and commit them with a clear message:

   ```bash
   git commit -m "Describe your change"
   ```

4. Push the branch to your fork:

   ```bash
   git push origin my-change
   ```

5. Open a pull request against the `main` branch and describe what you changed and why.

## Guidelines

- Keep changes focused: one fix or feature per pull request.
- Follow the existing style of the code and documentation.
- Test your changes before submitting (for example, check the calculator with a few known values such as P = 10000, R = 5, T = 3 → SI = 1500).
